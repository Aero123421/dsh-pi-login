# PiログインUI

公式DeepSeek Harnessのモデル設定画面に、Pi対応プロバイダーのログイン操作を追加します。ブラウザ認証、認証コード・APIキーの入力、キャンセル、保存済み認証の表示に対応します。

対応するプロバイダーと認証方法は本体のAuthorizationサービスから取得します。トークンの保存と更新は公式のPiアダプターが担当します。このプラグインが独自のPi SDKや認証情報の保存先を追加することはありません。

認証後に「プロバイダーのモデルを有効にする」を押すと、未設定のプロバイダーをモデル設定へ追加できます。既存設定を保持し、APIキー参照を自動で削除しません。

対応確認の対象は公式 `0.2.1-alpha.2` のソースです。実アカウントでのOAuthと、公式デスクトップ配布物へのインストールは未検証です。
