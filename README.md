# Pi接続・モデル管理

DeepSeek Harness用の独立PiアダプターとログインUIです。Pi SDK 1.1.0をプラグインの依存関係として固定し、DS本体の更新とは別に追従できます。

公式のメニュー、スイッチ、入力欄、モーダルを使用します。設定の追加領域からログインし、プロバイダーとモデルをON/OFFできます。オフにしても認証情報と設定は残ります。

組み込みPiアダプターを構成パッチで停止し、プラグイン版だけがモデルを登録します。設定は初回に取り込み、元の設定は保持します。Credentialsサービスの既存レコードを再利用し、トークンの更新はこのプラグインのSDKが担当します。会話変換、推論設定、ツール履歴、画像処理、ストリーム処理は元のアダプターを基にしています。

DSの標準フォームは独自の設定名前空間に未対応なので、操作は追加した欄を使用します。アンインストール後の再起動で組み込みアダプターに戻ります。その場合は元の設定が使われ、プラグイン側のON/OFF設定は適用されません。

Node.js 22.19.0以上。対象は公式0.2.1-alpha.2です。実アカウントのOAuth、公式デスクトップへのインストール、Windows・macOS実機は未検証です。
